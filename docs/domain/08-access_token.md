# 개요

사용자는 액세스토큰을 발급할 수 있다.

/me 페이지에 가면 액세스토큰 발급받기 버튼을 클릭할 수 있다.

임의로 액세스토큰이 발급되며 테이블명은 access_token  이다.
액세스토큰은 유효기간은 발급일로부터 7일치이다.
마이페이지에서 재갱신버튼을 누를 수 있다.

# 테이블 
id : 액세스토큰의 고유 식별자(숫자) auto increment
token : 액세스토큰 문자열 (문자열 제약 없음)
created_at : 액세스토큰 발급일 (timestamp)
user_id : 액세스토큰 발급받은 유저의 id (숫자) foreign key (member 테이블의 id 참조)

# access token 사용처
mcp 처럼 로컬환경에서 요구사항 ID 에 대하여 조회하고, Task를 만들라고 요청할 수 있다. 
- 요구사항 상태 변경 등등 로그인해서 할 수 있는 일들을 CLI 환경에서 로컬개발하면서 반영할 수 있다.
