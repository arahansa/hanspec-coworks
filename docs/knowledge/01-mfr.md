
# 개요
MFR은 Module(모듈), Feature(기능), Requirement(요구사항)의 약자로, 
소프트웨어 개발에서 시스템을 구성하는 요소들을 체계적으로 분류하는 방법입니다.

이를 통해 개발자들은 시스템의 구조를 명확히 이해하고, 
각 요소 간의 관계를 효과적으로 관리할 수 있습니다.

# 회원 모듈에 관한 MFR 예시

## Module(모듈)에 속하는 것들
1. 회원

## Feature(기능)에 속하는 것들
1.1 로그인
1.2 로그아웃

## Requirement - 요구사항에 속하는 것들
1.1.1 이메일 로그인
1.1.2 소셜 로그인 - 카카오
1.1.3 소셜 로그인 - 구글
1.2.1 로그아웃
