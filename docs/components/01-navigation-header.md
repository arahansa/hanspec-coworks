

# 개요
화면 상단에 나타나는 네비게이션 페이지

# 상태
`../02-member.md` 에서 회원의 상태에 따라 네비게이션이 달라진다.

`로그인한 경우` : 네비게이션 우측에 member.username 표현
`로그인하고 관리자(SUPER)인 경우`
`로그인하지 않은 경우` : 네비게이션 우측에 SignIn 버튼 표현

# 관리자(SUPER) 인 경우 나타나는 좌측 네비게이션
로그인한 MEMBER의 등급이 SUPER인 경우, 아래 컨텐츠 영역을 좌우로 나눠서 좌측에 sub navigation 메뉴들이 나타난다.
- 프로젝트 관리 : /admin/projects
- 회원 관리 : /admin/members
